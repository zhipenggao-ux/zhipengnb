本研究的核心学术问题界定为“基于异质性车辆（电动/普通单车）时空多任务需求联合预测的图结构重平衡调度优化问题（Heterogeneous Spatio-Temporal Demand Joint Forecasting and Rebalancing Problem）”。该问题的研究重点在于解析电动与普通单车在出行时空、距离与替代效应上的内在差异，建立双车型需求与比例预测模型，并在此基础上设计满足两类车辆动态补给与比例平衡的运筹调度策略。

## 一、 研究问题界定与切入点

* **核心矛盾：** 传统共享单车调度研究多将车辆视为同质化实体，而 Divvy Bikes 数据涵盖了普通单车（Classic Bike）与电动单车（Electric Bike）。电动单车具备骑行速度快、覆盖半径大、定价差异等特点，与普通单车在特定出行场景下存在显著的**替代效用**与**时空非对称性**。
* **预测难点：** 需同时预测每个站点在未来时间窗（如未来 1 小时/2 小时）内的**普通单车借/还需求量**、**电动单车借/还需求量**，以及两者的**动态供给比例**。
* **调度难点：** 调度不仅要补足站点的总缺口（避免无车可租或无位可还），还要满足用户对特定车型的偏好约束，避免出现“全是电动车导致低预算用户流失”或“全是普通车导致长途通勤需求失衡”的问题。

## 二、 论文章节脉络与整体框架

结构可设计为标准的六章研究生学术论文框架：

* **第一章：绪论**
* 研究背景（芝加哥共享单车发展、电单车引入带来的管理复杂性）。
* 异质性单车时空预测与调度问题的研究现状与痛点。
* 研究内容、技术路线图与创新点。


* **第二章：Divvy 异质单车出行数据挖掘与特征分析**
* 数据清洗、GPS 坐标对齐与异常值过滤。
* **异质性对比分析：** 分析普通单车与电动单车在骑行距离分布、早晚高峰潮汐效应、跨区域流动以及气象敏感度（温度/降水）上的统计学差异。
* 空间图拓扑结构构建（站点邻近度矩阵与历史 OD 转移概率矩阵）。


* **第三章：基于多任务时空图神经网络的双车型需求与比例预测**
* 时空图神经网络模型设计（图卷积提取空间依赖，时间卷积/注意力机制提取时间周期性）。
* **多任务学习（Multi-Task Learning）架构：** 底层共享时空特征，顶层多输出端同时预测普通车需求量 $Y_{\text{classic}}$、电动车需求量 $Y_{\text{electric}}$ 以及双车型比例 $R_{\text{ratio}}$。
* 预测效果对比实验（对比 Baseline：XGBoost, LSTM, STGCN 等）。


* **第四章：考虑双车型比例与容量约束的单车调度优化模型**
* 问题描述与符号系统定义（站点缺口、调度车容量、行驶路线、行驶成本）。
* 建立**混合整数线性规划（MILP）模型**：目标函数包含调度行驶成本最小化、站点缺口惩罚最小化、双车型比例偏离惩罚最小化。
* 求解算法设计（启发式算法或求解器实现）。


* **第五章：数据驱动的仿真验证与对比分析**
* 构建芝加哥真实路网环境下的 Trace-driven 仿真平台。
* 设置对照组（无调度、传统单车型调度、基于本文双车型比例预测的调度）。
* 从服务满意率（Unsatisfied Demand）、调度成本、双车型供需匹配度维度评价模型性能。


* **第六章：总结与展望**

## 三、 技术路径、算法与模型选型

| 模块 | 核心任务 | 可选路径与算法/模型 |
| --- | --- | --- |
| **数据处理与预处理** | 空间聚合与特征融合 | • **空间聚类：** Uber H3 六边形网格化或基于 K-Means/谱聚类的交通小区（TAZ）划分。<br>

<br>• **外部特征融合：** NOAA 芝加哥历史气温/降水/风速、节假日、CTA 地铁/公交站点邻近度。 |
| **时空需求预测** | 预测站点级双车型借还量及比例 | • **基准模型：** XGBoost, Random Forest, GRU/LSTM。<br>

<br>• **核心深度学习模型：** **ASTGCN**（结合注意力机制的时空图卷积网络）或 **STGNN-MTL**（多任务学习时空图神经网络）。利用图卷积 $GCN$ 捕捉站点间拓扑关联，时间注意力捕捉周期性。 |
| **重平衡调度优化** | 生成调度卡车的最优路线与搬运策略 | • **小规模精确求解：** **MILP**（混合整数线性规划），使用 **Gurobi** 或 **CPLEX** 求解器。<br>

<br>• **大规模启发式求解：** **ALNS**（自适应大邻域搜索算法）或 **GA**（遗传算法）。<br>

<br>• **动态实时调度（可选拓展）：** **DRL**（基于 Deep Q-Network 或 PPO 的深度强化学习）。 |

## 四、 落地实施与实操步骤

```
[原始Divvy数据集 + 芝加哥气象/路网数据]
         │
         ▼
[数据清洗、空间网格化(H3) & 异质性特征挖掘]
         │
         ▼
[构建多任务时空图神经网络(Multi-Task STGCN)]
  ├── 预测: 普通单车需求 Y_classic
  ├── 预测: 电动单车需求 Y_electric
  └── 计算: 预测供需缺口与动态车型比例 R
         │
         ▼
[构建双车型重平衡运筹优化模型(MILP / ALNS)]
  ├── 约束: 卡车容量、站点容量、时间窗
  └── 目标: 最小化调度成本 + 最小化双车型缺口惩罚
         │
         ▼
[基于芝加哥真实历史数据的仿真验证与性能评估]

```

### 落实步骤：

1. **构建图拓扑与特征张量：** 将 Divvy 站点映射为图节点 $V$，站点间的距离或历史骑行转移频次作为边权重生成邻接矩阵 $A \in \mathbb{R}^{N \times N}$。将时序特征（借还量、气象、时间属性）构建为三维张量 $X \in \mathbb{R}^{N \times T \times F}$。
2. **多任务 loss 设计：** 在预测神经网络中，损失函数设定为总损失联合优化：

$$\mathcal{L}_{\text{total}} = \alpha \mathcal{L}(\hat{Y}_{\text{classic}}, Y_{\text{classic}}) + \beta \mathcal{L}(\hat{Y}_{\text{electric}}, Y_{\text{electric}}) + \gamma \mathcal{L}(\hat{R}_{\text{ratio}}, R_{\text{ratio}})$$


3. **根据预测结果算缺口：** 计算每个站点 $i$ 在时间 $t$ 的普通车缺口 $D_{i,t}^c = \text{Demand}_{i,t}^c - \text{Supply}_{i,t}^c$ 与电单车缺口 $D_{i,t}^e = \text{Demand}_{i,t}^e - \text{Supply}_{i,t}^e$。
4. **调度模型求解：** 编写 Python 脚本，以预测出的 $D_{i,t}^c$ 与 $D_{i,t}^e$ 作为输入输入给 Gurobi 或 ALNS 算法，计算调度车从仓库出发、在各站点间装卸两类单车的最优路径与搬运量 $x_{i,j,k}$。
